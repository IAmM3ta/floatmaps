# Greenville Pilot Plan Outline (Minimal Viable Pilot)

## Objectives
- Prove user demand and willingness to use modular battery system
- Validate operations (pickup, return, gifting)
- Demonstrate net energy accounting and basic grid feedback potential
- Generate early data for unit economics and investor conversations

## Scope (Minimal)
- 8-12 kiosks in Greenville, SC metro area
- Focus on high-traffic PEV locations (trails, downtown, events)
- Target 500-1,000 active users in first 6 months
- Run for 9-12 months

## Key Success Metrics
- User adoption and repeat usage
- Net energy throughput per kiosk
- Return rates and SoC upon return
- Gifting adoption rate
- Operational reliability (uptime, maintenance)
- Early signals on grid services interest from local utilities

## Phases

**Phase 0: Pre-Pilot (Now - 2 months)**
- Finalize kiosk design and supplier
- Secure initial sites/permits
- Build backend integrations and user onboarding
- Recruit initial user cohort from local PEV community

**Phase 1: Soft Launch (Months 1-3)**
- Deploy first 4-6 kiosks
- Onboard users and collect feedback
- Iterate on FloatMaps and kiosk UX

**Phase 2: Full Pilot (Months 4-9)**
- Scale to 8-12 kiosks
- Run gifting and device integration features at scale
- Begin conversations with local utility on grid services

**Phase 3: Learnings & Fundraising (Months 10-12)**
- Analyze data
- Document unit economics
- Prepare for next funding round or expansion

## Budget Estimate (High-Level)
- Kiosk hardware + initial batteries: $600k - $900k
- Software & operations: $200k - $300k
- Site work & permitting: $100k - $150k
- Working capital & contingency: $150k - $200k

Total: ~$1.1M - $1.6M for a meaningful pilot

## Risks & Mitigations
- Permitting delays → Start early with city engagement
- Low initial adoption → Strong community outreach via local PEV groups
- Hardware issues → Phased rollout with learning loops

This pilot is designed to be the minimum credible step to de-risk the model for larger capital.
