# Detailed Pilot Plan - Greenville OPEV + FloatMaps Pilot

## Executive Summary
This is a minimal viable pilot designed to de-risk the core model with the least capital while generating credible data for larger funding rounds. Focus: Prove demand, operations, net energy accounting, and early grid interest in one city.

## Objectives
- Validate user adoption and willingness to use modular battery system
- Prove operational feasibility (pickup, return, gifting, device integration)
- Demonstrate accurate net energy consumption tracking and billing
- Generate early signals on grid services interest from local utilities
- Build real user testimonials and data for investors

## Scope
- **Location**: Greenville, SC metro area (strong existing PEV community)
- **Kiosks**: 10 kiosks (phased deployment)
- **Target Users**: 800–1,500 active users in first 9 months
- **Duration**: 12-month pilot

## Timeline

**Months 0-2: Foundation**
- Finalize kiosk hardware design and supplier contracts
- Secure initial 5 site locations and begin permitting
- Complete backend integrations (Supabase, Edge Functions, device lookup)
- Build and test gifting + return flow in FloatMaps
- Recruit initial 200-300 pilot users via local PEV groups and events

**Months 3-5: Soft Launch**
- Deploy first 5 kiosks
- Onboard users and run initial gifting and device integration tests
- Collect usage data and iterate on UX
- Begin conversations with local utility about grid services

**Months 6-9: Full Operation**
- Scale to 10 kiosks
- Run full feature set at scale (ghost racing, device tunings, gifting)
- Track net energy consumption and billing accuracy
- Gather qualitative feedback and testimonials

**Months 10-12: Analysis & Fundraising Prep**
- Analyze all data (adoption, energy throughput, operational metrics)
- Document unit economics per kiosk
- Prepare investor materials with pilot results
- Explore expansion locations and utility partnerships

## Budget Estimate (Detailed)

**Hardware & Deployment: $750,000 - $1,050,000**
- Kiosk manufacturing & installation (10 units): $450k - $650k
- Initial modular battery inventory: $250k - $350k
- Site work, electrical, permitting: $50k - $100k

**Software & Platform: $250,000 - $350,000**
- FloatMaps development & integrations: $150k - $200k
- Backend, Edge Functions, admin tools: $80k - $120k
- QR/gifting systems and testing: $20k - $30k

**Operations & Team: $300,000 - $450,000**
- Pilot operations lead + support: $120k - $180k
- Maintenance, logistics, insurance: $80k - $120k
- Marketing & user acquisition (local): $60k - $100k
- Contingency: $40k - $50k

**Total Estimated Pilot Budget: $1.3M - $1.85M**

## Success Metrics
- User adoption: >800 active users
- Kiosk utilization: Average 60%+ daily usage
- Return compliance: >85% of pickups have recorded returns
- Net energy tracking accuracy: >95%
- Gifting adoption: >15% of returns involve gifting
- Qualitative: Strong user testimonials and repeat usage
- Early utility interest: At least one MOU or serious conversation

## Risks & Mitigations
- **Permitting delays**: Start engagement with city immediately
- **Low initial adoption**: Leverage existing local PEV community heavily
- **Hardware reliability**: Phased rollout with rapid feedback loops
- **Utility interest**: Begin conversations early, even if informal

## Post-Pilot Path
Successful pilot → Use data to raise larger round for regional expansion (50-100 kiosks) while pursuing utility/grid partnerships.
